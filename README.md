# ألعاب «إبداع قلمي»

ألعاب تعليمية تفاعلية لتنمية مهارات الكتابة بخط النسخ لطلاب الصف السادس الابتدائي، ضمن مبادرة «إبداع قلمي».

- **المدرسة:** الطفولة المبكرة بالابتدائية الثالثة بخليص
- **إعداد المعلمة:** ساعدة السلمي
- **مديرة المدرسة:** نسرين المسعودي

## الألعاب

| اللعبة | الملف |
|---|---|
| أين يستقر الحرف؟ | `line.html` |
| شكل الحرف في موضعه | `forms.html` |
| رتّب حروف الكلمة | `order.html` |
| صيّاد الانقطاع | `joins.html` |
| تتبّع الحرف بإصبعك | `trace.html` |

الصفحة الرئيسية `index.html` تجمع الألعاب الخمس.

كل لعبة ملف HTML مستقل لا يحتاج إلى تسجيل دخول أو خادم أو اتصال بأي خدمة خارجية، والخط المستخدم هو Noto Naskh Arabic المضمّن بجانب الملفات (رخصة SIL Open Font License، انظر `OFL.txt`).
